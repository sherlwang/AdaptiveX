# PHY 检查点对照

适用于已经取得真实 DUT 输出和 MATLAB 参考的核验。调用项目现有算法，不用旧 HDL 输出替代 MATLAB 参考，不改变通信算法来迁就采集结果。

## 1. 先固定比较对象

记录共同输入的文件、配置和哈希，检查 TB 实际读入或实采回放使用了这些数据。明确每个检查点的有效传输条件、I/Q、lane 时间顺序、有符号性、位宽、小数位和已知流水延迟。

采集为“数值元数据列 + 打包 I 十六进制 + 打包 Q 十六进制”时，可用 [read_iq.m](scripts/read_iq.m)。先读 [数据约定与账本](references/data-contract.md)；此函数不是通用 ILA CSV 读取器，也不单独证明文件和帧完整。

## 2. 逐帧核对

- 根据 Tx 真值、实际输入区间和明确的滤波支持范围，预先确定应恢复帧。独立记录未完整供给、复位中断和流水尾部；不能从首次 Rx 锁定后才计数，或事后只留下成功帧。
- 先核对帧数、样本数、缺失、重复、顺序及块标志，再按接口规定的延迟和排列匹配。缺失帧没有可计算的 MER，仍计入未恢复数量。
- bit 对照按有效宽度逐位比较，同时检查总长度和元数据。公共前缀零误码不等于完整传输正确。
- 相同量化输入分别交给 MATLAB 算法和 HDL。需要区分计算与量化影响时，另用独立定点参考；保存原始无符号打包值、补码整数和缩放后的数值各自含义。
- 精确整数结果检查不一致数量及首个位置。浮点比较记录最大误差、RMS、LSB 口径；涉及星座质量时逐帧记录直接 MER 及 MATLAB/HDL 差值。不能靠增益、相位拟合或任意移位掩盖差异；诊断拟合另列。

## 3. 汇总结论

分别报告计划/完成案例数、应恢复/已恢复/缺失/重复帧数、译码前后 bit、整数对照和浮点/MER 结果。门限来自本次算法与量化要求，不预设通用 MER 门限。

“整数参考一致”“已测量浮点差异”“功能验收通过”分别表述。部分案例完成、只统计成功帧或仅有旧版对照，均不能写成整套链路全部通过。
