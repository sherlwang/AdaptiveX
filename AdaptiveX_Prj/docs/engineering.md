# 工程说明

## 1. 系统与模式

器件为 `xczu47dr-ffve1156-2-i`，工程使用 Vivado 2021.2。Tx 主数据流在 `src/tx/sources_1/tx/PHY_TOP.v`，Rx 主数据流在 `src/rx/sources_1/rx/PHY_TOP_Rx.v`。板卡接入、以太网、顶层连接、模式控制和通用处理保留可读 RTL。

| P | M | 调制 | 编码位宽 W | 符号率，Msymbol/s |
|---:|---:|---|---:|---:|
| 2 | 0 | BPSK | 2 | 409.6 |
| 2 | 1 | QPSK | 4 | 409.6 |
| 2 | 2 | 16QAM | 8 | 409.6 |
| 4 | 0 | BPSK | 4 | 819.2 |
| 4 | 1 | QPSK | 8 | 819.2 |
| 4 | 2 | 16QAM | 16 | 819.2 |
| 8 | 0 | BPSK | 8 | 1638.4 |
| 8 | 1 | QPSK | 16 | 1638.4 |
| 8 | 2 | 16QAM | 32 | 1638.4 |

AI 推荐模式号为 0～8，按 P 从小到大、每档 M 从 0 到 2 排列。Tx 的手动请求分别使用 P 和 M。

## 2. 实现与接口配置

| 端 | 模块 | 配置或用途 |
|---|---|---|
| Tx | `ldpc_encoder` | W=2/4/8/16/32，编码图固化 |
| Tx | `RRC_Shared` | span16，三档插值，12 路输出 |
| Rx | `Rx_Rate_Acquire` | P 识别、粗同步及帧描述，固定采样 offset=0 |
| Rx | `Rx_Header_Sync` | 动态 P，同帧确认与 ZC/PN 定位 |
| Rx | `Rx_FDE_Core_8` | 动态 P，2048 点 FFT → Mov_ZF/ZF → IFFT |
| Rx | `Rx_NLMS` | 动态 P/M，单复权重的成组更新与流水 |
| Rx | `Rx_Demap_9` | 动态 P/M，软信息输出 |
| Rx | `ldpc_decoder` | 动态 W，正常迭代上限，204.8/307.2 MHz 接口 |
| Rx | `rx_ai_switch` | 特征接口、推理与推荐控制，网络参数固化 |

每个核目录的 `core.json` 记录生成配置和文件哈希。`core.edf.gz` 用于综合实现，`core_sim.v.gz` 用于 XSim 功能仿真，`core_stub.v` 声明接口。构建入口展开载荷，将 stub 注册到综合、功能模型注册到仿真，再通过综合后置 hook 的 `update_design -strict` 填入 EDIF 并保存完整 DCP。

保留工程的 `source_mgmt_mode All`、BD 模块引用及 hook 注册顺序；仅综合 stub 会留下黑盒。功能模型带有 `NotValidForBitStream` 标记，应按上述用途分别使用。

P/M 与 Mov_ZF 窗长是运行时输入；内部精度、流水、FFT 点数、并行规模和模型权重已固化。需要改变这些配置或迁移器件、工具版本时，应使用相应设计输入重新生成并验证。

## 3. 接收与同步设置

接收抽样 offset 固定为 0。接收链完成 ZC/PN 帧起点定位、Moose 频偏估计、Mov_ZF、NLMS 与解码。

PN 精定位产生同帧确认事件，获取控制据此放行缓存帧；部分接口使用 `phase_*` 名称。抽样选择与输入波形延迟分别设置，帧同步负责定位帧起点。随包已验证的输入条件和范围见[验证结果](testing.md)。

## 4. 数据接口与缩放

| 接口 | 格式 |
|---|---|
| RF ADC/DAC | 4.9152 GSPS，实中频 |
| ADC 原始输入 | 12×16 bit，409.6 MHz；bit[15:0] 为最早样点 |
| 接收 DDC | 24 路，204.8 MHz；实数输入、复数输出 |
| 接收 RRC | P=2/4/8 个复符号/204.8 MHz；8×16 bit I/Q 容器 |
| FFT/IFFT | 2048 点，8 点/拍；低速输入按间隔插零 |
| 编码后接口 | W=P×b，b=1/2/4；32 bit/拍容器 |
| LDPC 译码 | 204.8 MHz 业务域，307.2 MHz 计算域 |

FFT 窗口和 FDE 输出为 signed16 F13，整数值除以 8192。FFT 为 DFT/32，IFFT 为 64×ifft，FDE 固定总增益为 2，因此 FDE MER 使用 2 倍发送星座参考。NLMS 输出为 signed16 F14，整数值除以 16384；BPSK 单位电平为整数 16384，MER 使用归一化发送星座。计算不作逐帧增益、相位或平移拟合。

有效标志、P/M、帧号和块号与数据共同传递。容器中的无效高位不计作业务数据，流水中的旧帧继续使用其原参数。

## 5. 帧结构与控制

以 204.8 MHz 拍数计：

```text
ZC 32 → PN 16/P
      → 训练1：CP9 + 训练256
      → 训练2：CP9 + 训练256
      → 数据1～6：每块 CP9 + 导频1 + 数据255
```

P2/P4/P8 的完整帧长分别为 2160/2156/2154 拍。切 P 时包含 Tx 控制产生的滤波冲洗区间，滤波尾部不属于编码 payload。接收 FFT 窗口对训练块和数据块均提前 5 拍，本地训练参考与 Mov_ZF 已包含相位关系。

人工复位低有效，拉低清状态、释放后持续运行。Tx 在帧边界采用目标 P/M，Rx 从接收数据识别。网表按自动识别链配置，保留 `PHY_TOP_Rx.AUTO_MODE` 的交付设置。
